# DPSWS TCP-unlimited benign microburst trials

This experiment runs the adopted `train_random_avg10` benign random
microburst condition with the TCP sender limit removed. All bottleneck,
queue, delay, transport, payload, and random burst-distribution settings are
inherited from the existing main runner.

Use `run.sh` as the entry point. Results are written under
`out/YYYYMMDD_HHMMSS/`.
